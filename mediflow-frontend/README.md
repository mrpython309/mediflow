# MediFlow Frontend

This directory contains the React + Vite frontend for the MediFlow application.

For complete project documentation, architecture details, and running instructions, please refer to the primary `README.md` in the root of the backend repository.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The development server will proxy `/api/*` requests to the local Spring Boot backend running on port 8080.
